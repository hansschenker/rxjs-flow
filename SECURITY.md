# Security Policy

## Scope

The maintained reference application is on `main`. Local verification and
durable storage do not establish production security or operational readiness.
The Cloudflare build keeps Todo access disabled until a separately reviewed
release access policy is implemented. The retained Node mode is for local
compatibility, uses memory storage and is not a production deployment target.

See [delivery limitations](docs/m09/delivery.md) before planning public access.

## Reporting a Vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/hansschenker/rxjs-flow/security/advisories/new)
when it is enabled for this repository. Its availability has not been verified
as part of M09, and no repository security setting was changed.

If a private reporting channel is unavailable, ask the maintainer to provide
one; a public issue requesting a channel should contain no vulnerability
details, credentials or exploit material. A GitHub profile does not provide a
general private-message service. This project does not promise a response
deadline or an automatic release schedule.

GitHub documents this workflow in
[privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
